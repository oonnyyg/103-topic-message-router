# topic-message-router

本地消息系统的主题订阅与保留消息路由工具。纯 Go 标准库实现，无网络服务：
从标准输入读取 JSONL 命令，向标准输出逐行返回 JSONL 结果，状态持久化到本地文件。

## 运行

```sh
go run . [-state path/to/state.json]
```

状态文件默认是 `./router-state.json`，也可用 `-state` 参数或 `ROUTER_STATE`
环境变量指定。订阅与保留消息在每次变更后原子写入，重启进程后自动恢复。

## 输入格式（每行一个 JSON 对象）

| 命令 | 字段 | 说明 |
| --- | --- | --- |
| `subscribe` | `client`, `filter` | 订阅过滤器；响应带 `replay`（按主题排序的匹配保留消息） |
| `unsubscribe` | `client`, `filter` | 取消订阅；不存在时报错 |
| `publish` | `topic`, `payload`, `retain` | 发布消息；响应带 `deliveries`（按客户端标识排序） |
| `query` | `what` | `what="subscriptions"` 或 `what="retained"` 查询当前状态 |

示例：

```json
{"cmd":"subscribe","client":"c1","filter":"sensors/+"}
{"cmd":"publish","topic":"sensors/t1","payload":"21.5","retain":true}
{"cmd":"query","what":"retained"}
```

每行输出为 `{"ok":true,...}` 或 `{"ok":false,"error":"..."}`。非法命令
（JSON 错误、未知命令、非法主题/过滤器、缺少客户端标识等）只返回错误，
不改变任何已有状态。

## 路由规则

- 主题按 `/` 分层，空层级保留，匹配区分大小写。
- 发布主题不能为空、不能含 `+` 或 `#`。
- 过滤器中 `+` 必须独占一层且只匹配一层（可匹配空层级）；`#` 必须独占
  一层且只能位于最后一层，匹配零层或多层。
- 首层为通配符的过滤器不匹配以 `$` 开头的主题（如 `#`、`+/x` 不匹配
  `$sys/status`）。
- 同一客户端的多个过滤器命中同一次发布时，只投递一次。
- 重复订阅同一过滤器不增加订阅数量，但仍会触发该过滤器的保留消息回放。
- 保留发布替换该主题的旧保留消息；空载荷的保留发布清除旧消息，但仍会
  投递给当前订阅者。普通发布不改变保留内容；新订阅只回放当前匹配的保留
  消息。
- 发布投递按客户端标识排序，回放按主题排序，消息内容原样投递不做改写。

## 测试

```sh
go test ./...
```

覆盖通配符边界（`+`/`#` 位置、`$` 主题、空层级、大小写）、重叠订阅去重、
保留消息替换/清除，以及重启后的订阅恢复与保留回放。
